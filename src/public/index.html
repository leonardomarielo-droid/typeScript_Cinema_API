Cinema API

API REST em TypeScript, Express e MySQL.

Rotas principais

  • /api/usuarios — cadastro e gerenciamento de usuários
  • /api/usuarios/login — autenticação JWT
  • /api/filmes — catálogo de filmes
  • /api/avaliacoes — avaliações e filtros por filme/usuário

Consulte README.md para exemplos de requisições.
